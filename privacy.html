Política de Privacidade

My Brain é uma ferramenta pessoal usada exclusivamente pelo seu dono. Ela acessa, em modo somente leitura, arquivos do Google Drive do próprio dono para salvá-los no computador pessoal dele.

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade. Os dados ficam armazenados localmente no computador do dono.

O uso de dados recebidos das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.
